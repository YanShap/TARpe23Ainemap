CASE-vahendid computer aided software engineering

Mis on CASE vahendid?
CASE vahendid on tarkvararakendused või tööriistad, mimida kasutavad paljud inimesed iga paev nad aitavad automatiseerida tarkvaraarenduse protsesse ning teha too ja elu lihtsamaks.

Mille jaoks neid kasutatakse?
CASE-vahendeid kasutatakse:
Süsteeminõuete kogumiseks ja modelleerimiseks
Andmebaaside ja süsteemide disain
Koodi genereerimine
Dokumentatsiooni loomine
Projektide haldamiseks ja testimiseks

Kuidas jaotatakse CASE-vahendeid?
CASE-vahendid jaotatakse tavaliselt kaheks:

  • Upper CASE kasutusel süsteemi analüüsi ja disaini faasis nt andmemudelid, uml diagrammid. Upper CASE
  • Lower CASE kasutatakse tarkvara arendamise ja testimise faasis nt koodi genereerimine, testimine. Lower CASE

Milliseid vahendeid saab kasutada inkrementaalse arendusmudeli elutsüklis?
Igas elutsükli etapis saab kasutada erinevaid CASE-vahendeid:

  • Nõuete analüüs: Enterprise architect, Visual paradigm
  • Disain: StarUML, lucidchart
  • Koodiarendus: Visual studio, Visual studio code
  • Testimine: selenium, junit
  • dokumentatsioon ja hooldus: confluence, git

Milliseid vahendeid olen ise juba kasutanud?
Mina olen kasutanud järgmisi vahendeid:
Visual Studio Code: koodi kirjutamiseks kooli projektid
GitHub: koodi kommitimine ja gruppi tood
